GitHub 做的事可以一句話講完：把用 Git 管理的程式碼，變成可協作、可審查、可自動化、可部署的線上專案。下面從「倉庫」到「開源」拆解。

1. 基礎：Git 與倉庫 · Git & Repos

一切的起點（單元 1、單元 2）。

Git本機版本控制工具GitHub雲端託管平台Repo專案倉庫Commit版本快照
Clone複製到本機Push / Pull上傳 / 拉取README專案門面.gitignore排除檔案

2. 協作：分支與 Pull Request

多人開發的核心流程（單元 3、單元 4）。

分支Branch 平行開發合併Merge 整合衝突Conflict 處理PRPull Request 合併請求
ReviewCode Review保護分支強制 PR 才能合併關聯Closes #issue

3. 管理與自動化 · Manage & Automate

把專案管好、部署出去、自動化（單元 5、單元 6、單元 7）。

Issues任務與 bug 追蹤Labels / Milestones分類與里程碑Pages靜態網站部署ActionsCI/CD 自動化

4. 開源：參與與貢獻

從使用者變成貢獻者（單元 8）。

Fork複製他人專案Contribute貢獻流程License授權gh CLI命令列 GitHub

箭頭方向即學習順序：先懂 Git 與 repo，再學協作、自動化，最後進入開源。

小結：GitHub = 「Git 版本控制」×「協作流程（PR）」×「平台服務（Issues / Pages / Actions）」×「開源生態」。每個都是獨立主題，但都圍繞同一個核心——讓寫程式變成可合作的事。
