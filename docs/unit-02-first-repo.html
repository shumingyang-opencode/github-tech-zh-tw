Repo 是什麼

Repo（Repository）＝專案倉庫，是 GitHub 上「一個專案」的容器。 它包含程式碼、版本歷史、Issue、PR、Wiki 等一切。可以是公開（人人可看）或私有。

流程一：在 GitHub 上建立 repo

網頁操作 · WEB UI
1. 右上角「+」→ New repository
2. 填名稱（如 hello-world）
3. 選 Public / Private
4. 勾選 Add a README（建議）
5. 按 Create repository
順帶一提：你現在看的這個教學站，其 repo 就是用這個流程建立的。 後面的單元 6會帶你親手做一次。

流程二：Clone 到本機

把 repo 複製到自己的電腦開始開發。HTTPS 網址形如 https://github.com/使用者/repo名.git。

命令 · COMMANDS
git clone https://github.com/you/hello-world.git
cd hello-world
結果 · RESULT
hello-world/
├── .git/      # 版本歷史（隱藏）
└── README.md  # 專案檔案

流程三：改檔 → 提交 → 上傳

Git 的日常循環只有三個步驟，全記住就夠了：

日常循環 · THE LOOP
git add .              # 1. 暫存（stage）：挑選要納入的變更
git commit -m "說明"   # 2. 提交（commit）：存成一個版本快照
git push               # 3. 推送（push）：上傳到 GitHub
指令作用類比
git add把變更加入暫存區打包要寄的東西
git commit存成一個帶說明的版本寫郵戳寄出
git push把本地版本同步到 GitHub快遞送到雲端
commit message 要寫清楚：給未來的自己與隊友看。好例子： fix: 修正登入頁空白；壞例子：update。

首次推送 · First Push

本地建立專案後要接上 GitHub（若你是先 clone 就略過）：

從零開始推送 · COMMANDS
git init -b main                    # 初始化，主分支叫 main
git add .
git commit -m "first commit"
git remote add origin https://github.com/you/hello-world.git
git push -u origin main             # -u 記住 upstream，之後直接 git push

README.md · 專案的門面

README 是訪客第一眼看到的文件（用 Markdown 寫——回顧我們的 Markdown 教學站）。

README.md / MINIMAL

# hello-world

A demo project.

## Usage

```bash
npm start
```

## License

MIT

解說 · EXPLAINED

# 專案名：一級標題。

一句話簡介。

Usage：怎麼安裝、怎麼跑。

License：授權（單元 8 詳談）。

夠用的 README 就是這四段。

.gitignore · 排除檔案

告訴 Git「哪些檔案不要追蹤」——例如 node_modules、建置產物、本機設定。

.gitignore · 範例
node_modules/
dist/
.env
*.log
.DS_Store
重要：.env、金鑰、Token 務必加入 .gitignore——一旦 push 上去， 就進入了 Git 歷史，刪掉也還在歷史裡。
看完這頁你應該能說出：
  • 如何建立、clone、push 一個 repo。
  • add → commit → push 三步循環的意義。
  • 好的 commit message 長什麼樣。
  • README 的四段基本結構。
  • 為什麼 .env 與金鑰要進 .gitignore。
