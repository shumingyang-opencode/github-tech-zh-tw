6.1 定義：GitHub Pages 是什麼

GitHub Pages 是 GitHub 內建的靜態網站託管服務——把 repo 裡的 HTML/CSS/JS（或 Markdown）直接變成網站，免費、附 HTTPS、綁 github.io 網域。

活教材：你正在看的這個網站、以及 Markdown / YAML / JSON 三個教學站，全部都是用 GitHub Pages 免費部署的。學完這單元，你就能複製同樣的事。

Pages 有兩種站：

類型repo 名稱網址
個人/組織站必須是 你.github.iohttps://你.github.io/
專案站任何名稱https://你.github.io/repo名/

6.2 方式一：Deploy from a branch（最簡單）

操作 · SETUP
1. repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: main  /  (root)
4. Save → 等 1~2 分鐘建置
5. 出現網址：https://你.github.io/repo名/
repo 內容
my-site/
├── index.html
├── about.html
└── assets/
    └── site.css
發布後網址 · URL
https://使用者.github.io/my-site/

# 專案網頁：/repo名/
# 個人網頁：/（repo 名必須是 使用者.github.io）
純靜態站記得：加一個空的 .nojekyll 檔，讓 GitHub 不要用 Jekyll 處理你的 HTML（本站就是這樣做的）。否則有些檔名/路徑可能被改寫。

6.3 方式二：用 GitHub Actions 部署（要建置時）

需要先編譯（Astro / Vite / Jekyll / MkDocs 等）的專案，用 workflow 建置後再部署。最簡版本：

.github/workflows/pages.yml · 片段
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: path: .
      - uses: actions/deploy-pages@v4

細節（on / jobs / permissions）在單元 7學到後就看得懂。這裡先會「複製貼上可用」。

6.4 方式三：gh CLI

gh 指令 · COMMANDS
gh repo create my-site --public --source=. --push
gh api --method POST   repos/USER/my-site/pages   -f "source[branch]=main" -f "source[path]=/"

6.5 自訂網域 · Custom Domain

想用自己的網域（如 blog.example.com）：

  1. Pages 設定填 CNAME：blog.example.com。
  2. 到你的 DNS 供應商加 CNAME 記錄指向 你.github.io。
  3. 等 DNS 生效（通常幾分鐘到幾小時），即可用 https://blog.example.com 存取。
兩件事容易忘：① 網域根（apex）多半要改 A record 指到 GitHub 的 IP；② 設定後 GitHub 會自動發 HTTPS 憑證，但需要一點時間，別急著改回去。

6.6 限制要知道 · Limits

項目限制
內容靜態檔案（無後端、無資料庫、無伺服器執行）
建置次數每月有配額（免費方案每小時約 10 次）
大小repo 建議 1GB 以下、單檔 100MB 內
用途個人/專案/組織網站 OK；商業「伺服器型」服務禁用
重要：Pages 是靜態的——沒有帳號登入、沒有伺服器端資料庫、沒有 API。需要後端時，改用其他服務（Firebase、Vercel、Render 等）。

6.7 Worked Example：部署你自己的教學站

步驟 · STEPS
1. 建 repo（如 my-site）
2. 放 index.html 與 assets/site.css
3. 加空的 .nojekyll
4. push 到 GitHub
5. Settings → Pages → Deploy from branch → main
6. 等 1–2 分鐘 → https://你.github.io/my-site/
驗收 · ACCEPT

✅ 網址能開
✅ HTTPS 生效（看得到鎖頭）
✅ 更新後 push，網站自動更新
✅ 需要時 CNAME 能指到自訂網域
