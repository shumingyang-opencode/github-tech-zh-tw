這個網站是什麼

一份把 GitHub 平台從帳號、第一個 repo，到開源貢獻做成中英對照深度教學的繁體中文網站。目標讀者是初階工程師與學生——你聽過 GitHub，甚至逛過別人的 repo，但想系統性地學會使用它完成真實工作。

每個單元都採用「定義/原理 → 教學步驟 → Worked Example → 常見錯誤 → 練習」的深度結構，並附「看完這單元你應該能說出」的驗收清單。

為什麼要學 GitHub

  • 現代開發的事實標準——工作、開源、作品集都在這。
  • 整合版本控制、協作、自動化與部署於一體。
  • 會 GitHub = 能參與全球任何開源專案。

本站建置

  • 規劃 8 單元深度課程（認識 → 上手 → 協作 → 自動化 → 開源）
  • 承襲既有教學站的深色 × 霓虹設計語言與架構慣例
  • 每個單元設計「定義/原理 + 步驟 + Worked Example + 練習 + 看完應能說出」結構
  • 新增術語表速查頁

本站本身就是 GitHub 的產物

你正在看的這站，以及 Markdown / YAML / JSON 教學站，都是由 OpenCode 撰寫、用 git 版本管理、推送到 GitHub，再透過 GitHub Pages 免費部署上線。學完單元 6，你也能做到。
