為什麼學 GitHub？

GitHub 是現代工程師的「數位身分證」：找工作時是你的作品集，協作時是團隊的版本中心，開源時是你向全世界展示程式碼的舞台。你正在看的這個教學站，以及姊妹站（Markdown / YAML / JSON），都是用 GitHub 管理、用 GitHub Pages 部署上線的——你正在使用的就是 GitHub 的產物。

立即體驗：Git vs GitHub

Git · 本機版本控制
git init          # 初始化
git add .         # 暫存
git commit -m "msg" # 記錄
GitHub · 雲端協作
git remote add origin https://github.com/you/repo.git
git push -u origin main   # 上傳
git pull                  # 拉取
一句話：Git 是「工具」，GitHub 是「家」——你把用 Git 管理的程式碼託管到 GitHub，就能跟別人一起開發。詳細差別見單元 1。
